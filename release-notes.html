Release Notes

Version history for ExcelLink for Autodesk® Revit®

Version 1.1.1
Latest Release October 2026

Improvements

  • Import now writes only the values that have actually changed, making imports faster and avoiding unnecessary element ownership requests in workshared models.
  • A detailed import summary is shown after each import: updated, already up-to-date, not applicable and rejected values are reported separately.
  • Autodesk® Revit® warnings raised during import (such as duplicate Mark values) are logged instead of interrupting the import with dialogs.
  • When exporting one sheet per category, each sheet now contains only the parameter columns that exist on that category, keeping workbooks compact.
  • The save location is now asked before the export starts; if the target file is open in Excel, the export is stopped before any work is done.

Fixes

  • Fixed a success message being shown even when an import could not be applied and was rolled back.
  • Fixed an import error when the same element appeared in more than one row; the first row is now used and duplicates are ignored.
  • Fixed numeric values being read with the system's regional format on some Windows locales, which could cause unchanged values to be rewritten.
  • Fixed parameter values shifting one column in per-category sheets in certain parameter selections.
Version 1.1.0
August 2026

New & Improvements

  • Enhanced cross-version compatibility for Autodesk® Revit® 2022 through 2027, resolving .NET Framework 4.8 and .NET 8 threading synchronization challenges.
  • Optimized thread-safe UI dispatching mechanisms ensuring zero interface freezes during rapid multi-category selections.
  • Integrated advanced dynamic Discipline and Category Type filters.
  • Improved performance and stability across Model, Selection, and Active View scope switches.
Version 1.0.0
Initial Release March 2026

New

  • Export Autodesk® Revit® element parameters to .xlsx with per-category or single-sheet output.
  • Import updated values back to Autodesk® Revit® in a single transaction using element Unique IDs.
  • Linked document support and configurable type parameter inclusions.
