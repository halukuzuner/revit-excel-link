Release Notes

Version history for ExcelLink for Autodesk® Revit®

Version 1.1.0
Latest Release August 2026

New & Improvements

  • Enhanced cross-version compatibility for Autodesk® Revit® 2022 through 2027, resolving .NET Framework 4.8 and .NET 8 threading synchronization challenges.
  • Optimized thread-safe UI dispatching mechanisms ensuring zero interface freezes during rapid multi-category selections.
  • Integrated advanced dynamic Discipline and Category Type filters.
  • Improved performance and stability across Model, Selection, and Active View scope switches.
Version 1.0
Initial Release March 2026

New

  • Export Autodesk® Revit® element parameters to .xlsx with per-category or single-sheet output[cite: 4].
  • Import updated values back to Autodesk® Revit® in a single transaction using element Unique IDs[cite: 4].
  • Linked document support and configurable type parameter inclusions[cite: 4].
