User Guide

ExcelLink for Autodesk® Revit® — Version 1.1.0  ·  Compatible with Autodesk® Revit® 2022–2027

Installation

Run the installer downloaded from the Autodesk® App Store. ExcelLink supports cross-version compatibility across both .NET Framework 4.8 (Revit 2022–2024) and .NET 8 (Revit 2025–2027) environments seamlessly.

For all users:

%ProgramData%\Autodesk\ApplicationPlugins\ExcelLink\

For specific user:

%AppData%\Autodesk\ApplicationPlugins\ExcelLink\

Trial Mode

ExcelLink includes a built-in trial mode with an export limit of 10 elements per category. No registration required[cite: 4].

License Activation

Activate your product using the online license activation window with a 30-day offline grace period[cite: 4]. Contact: ahuzuner@gmail.com

Exporting Parameters

1 — Selecting Categories & Filters

The left panel lists all model categories containing elements. Version 1.1.0 introduces advanced filtering capabilities:

  • Category Type & Discipline Filters: Filter categories dynamically by discipline (e.g., Common, Architecture) and category types.
  • Scope Selection: Switch effortlessly between Model, Selection, and Active View scopes.
  • Linked Documents & Type Parameters: Toggle options to include linked document instances or family type parameters[cite: 4].

2 — Selecting Parameters

Choose from standard parameters or utilize the Related Parameters panel to map intelligent parameter strategies. Drag and drop to reorder columns[cite: 4].

3 — Running the Export

Click Export to Excel to generate a structured .xlsx file[cite: 4].

Working in Excel

Edit values safely in Microsoft Excel. Do not modify Row 1 or Column A (Unique ID) as they are required for matching rows back to Revit elements[cite: 4].

Cell Color Coding

  • White — Writable instance parameter[cite: 4].
  • Light Pink — Read-only parameter[cite: 4].
  • Light Yellow — Type parameter[cite: 4].
  • Brick Red — Parameter does not exist on this element[cite: 4].
  • Light Gray — Element belongs to a linked document[cite: 4].

Importing Back to Autodesk® Revit®

Click Import from Excel to read changes back. Version 1.1.0 features optimized thread-safe UI dispatching, ensuring robust roundtrips across all Revit versions (2022–2027) without interface freezing[cite: 4].

Saving Configuration

Save and load your category and parameter selections via .json configuration files[cite: 4].

Linked Documents

Export parameters from loaded link instances alongside host model elements. Linked elements are marked with a gray background and cannot be imported back[cite: 4].
